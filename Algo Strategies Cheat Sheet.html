VINCERE TRADINGALGO STRATEGY REFERENCE
ORB Squeeze Trend Fair value gap

ORB

First 20-30 min sets the high/low range. Trade fires when price closes inside the range then breaks out above or below.

SQUEEZE

Identifies tight consolidation periods where price is coiling. Enters on the directional breakout when energy releases.

TREND

Catches sustained directional moves off support/resistance in the 2nd half of the NY session. Infrequent, 1:1 R/R.

FAIR VALUE GAP

Identifies large price imbalances. Enters on retrace to fill the gap. TP is dynamic based on gap size and formation speed.

PF VERSION

If an algo has a PF variant (e.g. OGX PF), always use it on prop accounts. FSA has no PF version - use as-is on prop accounts.

VARIATIONS V1-V5

V1-V5 are different entry/exit settings, not risk levels. All accounts in the same group and cycle must run the same variation to avoid hedging.

CHOP WARNING

ORB algos perform best on clean directional opens. False breakouts in choppy sessions are the algo following its rules - not a malfunction.

CONTRACT ROLLOVER

Roll contracts every 3-4 days via Tools > Database Management. Stale contracts = no trades. Restart NT to trigger the rollover prompt.
